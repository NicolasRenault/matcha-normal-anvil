# Matcha Normal Anvil

Change Klei's [Matcha Flavoured](https://modrinth.com/datapack/matcha-flavoured) default texture of the Chipped and Damaged anvil to match the base anvil texture.

Base anvil texture comes from Klei Wright. I only changed the Chipped and Damaged anvil textures. Please [support Klei](https://ko-fi.com/kleiwright) if you enjoy their work.
